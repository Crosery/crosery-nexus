## 判读（诚实版）

1. **FD：无泄漏。** 第 1 轮 34-35 → 40，第 2 轮 35 → 30；连接关闭后**回到 30（= 加载前基线）**。两轮合计约 **25 万次 SSE 连断、100 万次 API 调用**，零句柄泄漏。
2. **heapTotal 稳定在 87-90MB**（没有随负载持续抬高）= 没有容量型增长。
3. **heapUsed 是 GC 锯齿**（22-54MB）。第 1 轮的低点基线在 8 分钟内从约 23MB 抬到约 35MB（静置后 30.9MB）。**单轮无法把这种轻微抬升与「慢泄漏」区分开**——这正是必须用 read-only-sampler.mjs 长期采样的原因。
4. **RSS 平台在 200-208MB**：V8 不把已用页还给 OS，属正常现象；判断泄漏要看 FD 与 heapUsed 低点基线，不看 RSS 单点。

**边界（重申）**：两轮合计只覆盖**分钟级快泄漏**。「跑几天才涨」的慢泄漏**本轮未证明，也不构成结论**。
