## 篡改/伪造/重放（临时实例 8850）
原 cookie                  -> 401
伪造远期过期+原签名        -> 401
改一位签名                 -> 401
登出后重放同一 cookie      -> 401   ← 200 = 无服务端吊销
换 SESSION_SECRET 重启后   -> 401（见报告）
